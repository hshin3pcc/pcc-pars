📋 PARS Fill — on your phone

Fills the PARS attendance form right on your iPhone from the marks you copied in the PARS Attendance app — no Mac needed. It never taps Save/Certify: you review the values and do that yourself, per class, always.

Install (one time)

  1. Copy the bookmarklet code:
  2. In Safari, bookmark any page (Share → Add Bookmark) and name it PARS Fill.
  3. Open Bookmarks (book icon) → Edit → PARS Fill → replace its URL with the copied code → Done.

Each week

  1. PARS Attendance app → 📋 Copy marks (covers every class).
  2. Open PARS in Safari, log in, select the class + open week.
  3. Tap the address bar, type PARS Fill, tap the bookmark. Allow the paste when Safari asks.
  4. Review the filled values → tap PARS's own Save / Certify. Next class: select it in PARS, tap the bookmark again (the copied marks cover all classes).

The Shortcut (the path that works on modern iOS)

Modern iOS silently kills javascript: bookmarks (even from the bookmarks panel), so use an Apple Shortcut. The pasted code is a tiny loader; the real code loads from this repo on every run (updates automatically). Build it in exactly this order — the ordering matters:

  1. Settings → Shortcuts → Advanced → enable Allow Running Scripts.
  2. Shortcuts app → + → rename it PARS Fill.
  3. Tap ⓘ → turn on Show in Share Sheet FIRST.
  4. In the "Receive … input" header that appears: set the types to Safari web pages only.
  5. NOW add the action Run JavaScript on Web Page — and verify it reads "Run JavaScript on 🔷Shortcut Input" (a blue token, not a gray placeholder — if gray, tap it and pick Shortcut Input). An unbound action "succeeds" without ever running — the #1 silent failure.

Each week

  1. PARS Attendance app → mark each class → 📋 Copy marks (covers every class).
  2. Safari → PARS → select the class + open week → Share → PARS Fill.
  3. A panel appears on the page: tap 📥 Read marks from clipboard & fill → Allow the paste (the manual paste box below is the fallback).
  4. Review the filled values → tap PARS's own Save / Certify. Next class: select it, Share → PARS Fill again.
