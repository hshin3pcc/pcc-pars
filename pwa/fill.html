📋 PARS Fill — on your phone

Fills the PARS attendance form right on your iPhone from the marks you copied in the PARS Attendance app — no Mac needed. It never taps Save/Certify: you review the values and do that yourself, per class, always.

Install (one time)

  1. Copy the bookmarklet code:
  2. In Safari, bookmark any page (Share → Add Bookmark) and name it PARS Fill.
  3. Open Bookmarks (book icon) → Edit → PARS Fill → replace its URL with the copied code → Done.

Each week

  1. PARS Attendance app → 📋 Copy marks (covers every class).
  2. Open PARS in Safari, log in, select the class + open week.
  3. Tap the address bar, type PARS Fill, tap the bookmark. Allow the paste when Safari asks.
  4. Review the filled values → tap PARS's own Save / Certify. Next class: select it in PARS, tap the bookmark again (the copied marks cover all classes).

If the bookmark does nothing / shows "JavaScript is not allowed"

Newer iOS versions block javascript: bookmarks. Use the Shortcut instead — same code, Apple's sanctioned path:

  1. Copy the Shortcut code:
  2. Shortcuts app → + → search for the action Run JavaScript on Web Page → add it → paste the code into its script field.
  3. Name it PARS Fill. In the shortcut's info (ⓘ) panel turn on Show in Share Sheet.
  4. If iOS asks: Settings → Shortcuts → Advanced → enable Allow Running Scripts.
  5. Each week: on the PARS page in Safari → Share → PARS Fill → allow the paste → review → Save/Certify.

Generated by npm run build-bookmarklet — do not edit by hand. The code is built from the same tested core as the desktop extension (fail-closed class matching), runs only on the PARS page, and contains no student data.
